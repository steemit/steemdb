# JSONL Replay Tool

This tool reads operations from a JSONL file (generated by steemd ingest plugin in dry-run mode) and sends them to the `cold_ingest` service via HTTP POST.

## Purpose

- Test `cold_ingest` service without running steemd
- Debug data processing issues
- Verify end-to-end data flow
- Replay specific block ranges

## Usage

### Basic Usage

```bash
# Send all operations from jsonl file to cold_ingest
../bin/jsonl_replay -file /path/to/ingest_20260111_081033_778.jsonl
```

### With Rate Limiting

```bash
# Send at 1000 operations per second
../bin/jsonl_replay -file /path/to/ingest.jsonl -rate 1000
```

### Specific Block Range

```bash
# Send only blocks 1000-2000
../bin/jsonl_replay -file /path/to/ingest.jsonl -start-block 1000 -end-block 2000
```

### Custom Endpoint

```bash
# Send to a different endpoint
../bin/jsonl_replay -file /path/to/ingest.jsonl -endpoint http://localhost:9090/ingest/applied_op
```

### Verbose Output

```bash
# Show detailed progress
../bin/jsonl_replay -file /path/to/ingest.jsonl -verbose
```

## Options

- `-file`: Path to JSONL file (required)
- `-endpoint`: Ingest endpoint URL (default: `http://localhost:8080/ingest/applied_op`)
- `-rate`: Operations per second (0 = no limit, default: 0)
- `-start-block`: Start from block number (0 = from beginning, default: 0)
- `-end-block`: End at block number (0 = to end, default: 0)
- `-verbose`: Verbose output (default: false)
- `-show-errors`: Show HTTP errors (default: true)

## Examples

### Test with Small Block Range

```bash
# Test with first 100 blocks
../bin/jsonl_replay -file test/steem-test/data/ingest/ingest_20260111_081033_778.jsonl \
  -start-block 1 -end-block 100 -verbose
```

### Simulate Real-time Replay

```bash
# Send at realistic rate (e.g., 100 ops/sec)
../bin/jsonl_replay -file test/steem-test/data/ingest/ingest_20260111_081033_778.jsonl \
  -rate 100 -verbose
```

### Quick Test

```bash
# Send first 10 blocks quickly
../bin/jsonl_replay -file test/steem-test/data/ingest/ingest_20260111_081033_778.jsonl \
  -start-block 1 -end-block 10 -rate 1000
```

## Output

The tool provides:
- Progress updates every 5 seconds (operations sent, success count, errors, last block, ops/sec)
- Final summary with total statistics
- Error messages if HTTP requests fail

Example output:

## Use Cases

1. **Testing cold_ingest**: Verify that the service correctly processes operations
2. **Debugging**: Identify issues with specific block ranges
3. **Performance testing**: Test with different rates
4. **Data validation**: Ensure data is correctly written to MongoDB

## Notes

- The tool reads the JSONL file line by line, so it can handle very large files
- Each line should be a valid JSON object matching the ingest plugin format
- The tool respects block number filters, so you can replay specific ranges
- Rate limiting helps simulate realistic replay speeds
